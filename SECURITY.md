# Security

Aether is an early developer preview built by one person. It has not had an independent security audit. Please read [how it is protected and what it does not protect against](https://aether.alvinyeboah.com/security) before relying on it.

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

**[Open a private security report](https://github.com/alvinyeboah/aether/security/advisories/new)**

Include:

- the Aether version (**Aether → About Aether**) and your macOS version,
- what you did, what you expected and what happened,
- a proof of concept or steps to reproduce, if you have one.

Please do not include real passwords, tokens or other people's personal data.

## What to expect

- Reports are read by one person, on a best-effort basis. Expect an acknowledgement within a few days.
- Fixes ship as a new release, notarized and published here. Aether can check for updates itself (Settings → General → Updates).
- Please allow a reasonable time to fix a problem before discussing it publicly. Good-faith research that avoids other people's data and does not disrupt others is welcome.

## Supported versions

Only the latest release receives fixes.

## Scope

In scope: Aether the application (this repository's releases) and its website.
Out of scope: vulnerabilities in WebKit or macOS (please report those to Apple), and issues in websites you visit with Aether.

The machine-readable policy is at <https://aether.alvinyeboah.com/.well-known/security.txt>.
