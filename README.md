<h1 align="center">Aether</h1>
<p align="center">Room for the web. A native macOS browser.</p>
<p align="center"><a href="https://aether-browser.royal-bell-9386.chatgpt.site">Website</a> · <a href="https://github.com/alvinyeboah/aether/releases">Developer previews</a> · <a href="https://github.com/alvinyeboah/aether/issues">Feedback</a></p>

Aether brings a structured workspace sidebar, a compact interactive tab rail, and a little more breathing room to the web. Built with native AppKit and WebKit for Apple Silicon.

## Try the developer preview

[See releases and download details](https://github.com/alvinyeboah/aether/releases).

Requires **Apple Silicon and macOS 14 or later**. Native glass uses macOS 26 or later, with interactive glass on macOS 27.

**This is an early developer preview.** Current builds are ad-hoc signed, not notarized by Apple. iCloud passkey sign-in and automatic password filling are not verified. Please assess the release notes before using it for everyday browsing.

## Inside Aether

- Tabs, spaces and separate local profiles.
- A compact sidebar with visible, selectable and closable tabs, space/profile menus, and browser controls.
- Lateral space swipes over the sidebar in both layouts; page gestures stay with the webpage.
- Local address suggestions from the current profile’s tabs, bookmarks and history, plus Google search.
- A command palette for navigation, saved-content search and browser commands.
- Native split browsing and a quieter start page with the metallic Aether orbit.
- Settings for startup, appearance, motion, suggestions and workspace behavior.
- A local Dia migration preview for readable bookmarks and history. Imports are additive and skip duplicates; the original stays untouched.

Migration does not transfer encrypted live sessions, passwords, signed-in cookies, extensions, or Dia-specific AI data. Some history files require Dia to be closed or a readable export.
